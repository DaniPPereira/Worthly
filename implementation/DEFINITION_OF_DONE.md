# Definition of Done

A feature is done only when: - acceptance criteria pass; - OpenAPI
updated; - migration safe/tested; - ownership authorization reviewed; -
financial invariants unaffected or tested; - no sensitive logs; -
provider failure path handled; - idempotency considered; -
unit/integration/contract tests added; - Web/Mobile states considered if
endpoint is client-facing; - docs/ADR updated when decision changes; -
CI/security gates pass.
